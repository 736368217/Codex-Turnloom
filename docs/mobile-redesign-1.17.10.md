## 界面变化

- 固定浅色主题，白底阅读区、淡蓝色用户消息；助手回复减少边框，正文 15px、行高 1.7，角色与时间 12px。

- 输入区统一圆角与聚焦反馈，模型名按剩余空间截断，模型面板以输入区为锚点。
- 插件、技能、附件、发送、停止、刷新、工具详情与抽屉按钮保持至少 44×44px。修复运行中停止按钮越界和窄屏入口被隐藏的问题。
- system/developer 记录跟随工具详情开关显示，普通视图收起；内容计数随视图变化，用户角色中文化为「你」。
- 窄屏布局按窗口宽度判断，键盘压低高度时保持单栏。
- 登录与引导页装饰文案中文化，增加按钮按下、禁用与减少动态效果状态。

## 验收限制与剩余问题

- MuMu 实例 1：Android 15、1080×1920、density 480，WebView 110.0.5481.154.1。原生电脑列表可以显示，两台电脑状态为在线；打开 PI-Desktop 后，网页侧栏与搜索控件能够渲染，列表停在「加载中」。刷新及后端重启后现象仍在，原因未定位。原生完整工作区验收保持未通过。
- WebView 控制台未提供可用错误，实例没有暴露 WebView 调试 socket。不能据此认定内核版本或公网链路是根因。
- uiautomator 两次成功写出节点 XML 后以 139 退出，crash buffer 指向 uiautomator，未观察到 com.codexpocket.mobile 崩溃；该工具异常独立记录。
- Ego 与内置浏览器截图接口超时。保留了此前可见的页面截图及安卓 screencap 文件；最终效果的检查依据以 CSS 实际计算值、界面节点、交互结果和 OCR 为准，不宣称完成最终原生全页目视验收。
- 原生加载问题的最短后续路径：在能够暴露 WebView 控制台的测试环境中，捕获 app.js 初始化与模块加载错误，再按失败点复验。本轮没有改写加密连接配置。

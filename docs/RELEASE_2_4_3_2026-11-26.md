# 2.4.3 — 软键盘、底栏渐隐、归档与设备卡（2026-11-26）

App `2.4.3`（versionCode `102`）· 电脑端服务同步升级（内嵌同一颗 APK）

这一版收 `b40e052` 之后 8 个 `app/` 修复，没有新功能。真机 `3492047a` 全程 `unauthorized`，**真机未测**；320 档用模拟器证据并在下面逐条标了出处。

## 1. 连接页：软键盘不再盖住「验证并连接」

**根因**：`app/src/screens/ConnectScreen.tsx:157` 只在「展开手动表单」时调一次 `scrollIntoView`，输入框聚焦、键盘顶起之后不再滚动；`.tl-connect-scroll`（`app/src/theme/globals.css:463`）本身 `overflow-y: auto` 可滚，但底部只留 `24px + safe-area`，键盘占掉半屏后按钮就落在可视区外。

**现在**（`174d656`）：新增 `app/src/lib/keyboardReveal.ts`——`revealOffset(rect, visibleBottom, margin = 12)` 带 `offset > 0` 守卫（没被挡就不动用户的滚动位置），`visibleBottomOf()` 优先 `visualViewport`、回退 `innerHeight`；两个输入框聚焦时触发，另挂 `resize` / `visualViewport.resize` / `orientationchange` / `focusin` / `focusout`。键盘态底部留白走 `.tl-connect-scroll.is-editing`（视口比见过峰值缩 >96px 且表单内有焦点），键盘收起后 `shrunk` 变假、`.is-editing` 自己撤掉，焦点由 `form.contains(activeElement)` 保住。

**证据**（`emulator-5554`，真软键盘 + `elementFromPoint` 真点击，构建 `40a6a0b`，APK sha256 `90765eda7eb6b4323f2ee9e2b3c1f1d1473cc0ec9a272008a0ad9cc85ecf18db`）：

| 视口 | 留白 | 滚动 | 按钮底边 / 视口 | 余量（要求 ≥12） |
|---|---|---|---|---|
| 320×597 | `padding-bottom: 120px` | 268 px | 259 / 338 | **79 px** |
| 320×520 | `padding-bottom: 120px` | 331 px | 197 / 213 | **16 px** |

两档 `elementFromPoint` 均命中按钮、焦点留在密码框。`test/app-connect-keyboard.test.cjs` 5 项锁两档偏移、`NaN`/`Infinity` 视口、`visualViewport` 回退。

## 2. 底部导航：渐隐而不是硬切

2.4.2 的 `globals.css` 有一条 blanket `.tl-tabbar [role="tab"] { transition: none }`，把 `.tl-tabbar-item` 的 120ms 颜色过渡一并摁掉，选中切换是瞬间的，过渡只活在 `:active` 里。

**现在**（`451346a`）：删掉那条 blanket 规则，把过渡落到**基态**——`.tl-tabbar-item { transition: color 120ms ease }`，`svg` 与 `.tl-tabbar-label` 各自 `transition: opacity 120ms ease`，`:active` 只留 `opacity: .5`。新增 `test/app-tabbar-motion.test.cjs`（T1–T4：基态声明、`:active` 不含 transition、门禁① 无蓝底无 `!important`、组件只出状态）。

**证据**（同上构建）：按下 `1.0 → 0.5` 约 **116 ms**，按住稳定 `0.5`，抬手约 **117 ms** 回到 `1.0`；`svg` 与 label 同步，零位移、无回弹；底栏 `3 × 107 × 56` 贴底，不压手势条；`320` 三页 `docW = scrollW = 320`、overflow 0。

## 3. 归档：换到 native 槽、零状态留出口、触摸补到 44px

- `f30b182`：归档表以 native 槽（`secureGet` / `secureSet`）为唯一权威，`localStorage` 的 2.4.2 旧键只迁一次，迁完写 `turnloom.archivedThreads.migrated=1`，之后永不回读旧表——native 读失败宁可显示「没有归档」，也不把用户已取消归档的会话搬回来。
- `dd64098`：归档计数归零时「显示/隐藏归档会话」不再跟着消失（守卫改成 `showArchived || archivedCount > 0`）。这是 2.4.2 的真缺陷：展开后取消最后一条归档，按钮一起消失，列表停在「只显示归档」且没有出口。
- `3f8a901`：`.tl-archive-toggle` 的 `min-height` 从 `40px` 提到 `44px`。40px 是 2.4.0 起的老账，不是 2.4.3 的回归。

测试：`test/app-thread-archive.test.cjs` 7 项 + `test/app-archive-toggle.test.cjs` 4 项（含从 CSS 读 `min-height ≥ 44` 的守卫）。

## 4. 设备卡：能发现失联，不再泄露内部地址

`e13f453`：设备卡改成三行式，死链路会自己报出来；`127.0.0.1:8787 · 在线 · 刚同步` 这类把 host 内部信息摊在卡片上的写法删除，只在离线时出 chip。320 档 `.tl-plat-meta` 原有截断（186/212）随之消失。

## 5. 设置页：标题只留机器名

`57440cd` + `1edee89`：`.tl-settings-main` 是 `flex: 1; min-width: 0` 的列，标题与副行都是 nowrap + ellipsis，可用宽度只有 138px，装不下「机器名 + 平台名」两件事。中间版本把平台名挪到副行被算术否决（副行 11px 下整句 37 字符：`Codex Desktop · ` 16 + 地址 21，实测约 6.6px/字符 ≈ 240px，而可用宽度 138px，只能露到 `Codex Desktop · http:/…`，等于两样都半截）。最终：标题只留机器名，副行退回只放地址，平台名不在这行出现——设备页与「当前 Codex Desktop」已有该信息。`test/app-settings-row.test.cjs` 三条形状断言锁住。

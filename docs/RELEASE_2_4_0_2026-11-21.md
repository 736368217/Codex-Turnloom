# 2.4.0 — 每一屏都留下有人需要的东西（2026-11-21）

App `2.4.0`（versionCode `99`）· 电脑端服务同步升级（新增 `GET /api/search`、`/api/threads` 的 `active`）

这一版不是加功能，是**按「用户什么时候会需要它」重新过了一遍三个页面**：删掉 6 个说不清触发时刻的控件，合并 3 组重复入口，新增 5 个真的会被用的东西。设置页从 11 个可点控件变成 8 行、每行一个动作。

## 会话页

- **搜索能搜正文了**：`GET /api/search?q=` 同时在标题、项目名、消息正文里找；中文按子串匹配（不分词、不做拼音），英文大小写不敏感。结果分「会话」「内容命中」两组，命中片段高亮。搜索框搬进固定区——滚到列表底部也不会消失。
- **搜索框不再匹配会话 ID**：以前输一个字母会命中一堆 uuid，标题和正文都没命中的行也会冒出来。
- **运行条分两类**：「N 运行中 · M 待你处理」。运行中可以就地停止，待处理的点「去处理」直接进会话。计数来自服务端的 `active`，与列表分页无关——第 2 页之后在跑的会话也数得到。
- **运行中数量对不上的修法**（Human 当晚报的「电脑 4 / 手机 2」）：一部分是客户端只数 `thinking`，另一部分是服务端两个真实缺陷——状态解析只看文件尾 512 KiB（长会话的 `task_started` 被输出挤出去 → 误判 ended），以及等授权超过 10 分钟被判 stale 后连 `interactionRequired` 一起变假。三个地方一起修。
- 删掉「刷新会话列表」按钮：进入会话页、回到前台都会拉一次，按钮是在给缺陷打补丁。

## 对话页

- **左侧来源头像**：AI 回复行左侧 24px 圆角方块，按当前入口显示 `CX` / `PI`；用户侧不加头像，工具与系统行不加。
- **日期分隔**：今天 / 昨天 / `M月D日`，同一天只出现一次。
- **「跳到最新」**：上翻阅读时新消息到达，右下出现按钮；不回到底就不自动抢滚动位置。
- 删掉头部那个「运行中转圈」——副标题已经写着运行中，转圈只是动效。

## 设备页

- **每张电脑卡直接显示平台标记**（`CX` / `PI`）：非当前电脑也显示它上次发现过哪些平台，不再只写「N 个平台」。
- 删掉「N 台已配对」那行——数得出来的东西不用占一行。

## 设置页

删：测试连接（顶部状态已表达）、切换电脑上的服务（设备页同一动作）、上传诊断独立行、运行信息独立 sheet、检查更新独立行、清除缓存独立行。
并：诊断 = 运行信息 + 上传日志 + 清缓存 + 重新同步，一个 sheet；关于 = 版本行（点即检查更新）+ 更新日志 + 许可 + 反馈。
加：**字号**（小 / 标准 / 大，只缩放正文与列表标题，不动图标与 44px 命中区）、**会话列表默认视图**、**触感反馈**开关。

## 安装

- **覆盖安装**：同一签名证书 `2F:EB:63:C5:…:FA:9C`，`versionCode 99 > 98`。
- **电脑端服务必须一起升级**：搜索与运行条依赖 2.4.0 的 `/api/search` 与 `/api/threads.active`；旧服务端会明确降级（搜索只按标题/项目/预览匹配，运行条退回当前页），不会假装搜过正文。
- 旧服务端的降级提示写在搜索框下方，不静默。

## 明确不做（2.4.1 再说）

- **手机日志不是「手动上传」**：发送成功后本来就会自动上传（`dataStore.ts` 调 `uploadDiagnostics`，最近 200 条），诊断 sheet 里的「上传日志」是第二条重复入口——2.4.1 删掉按钮，并给服务端 `logs/phone/` 加按天总量上限（现在只有单文件 1,000 行）。2.4.0 不动这条链路。
- **正文索引只覆盖尾部窗口**：>4 MiB 的会话只索引尾部约 512 KiB / 400 条消息，更老的正文搜不到；历史分页搜索不在这一版。
- **当前电脑卡不挂平台标记**：它那一行只回答「这台电脑现在通不通」，平台卡就在它下面一层且默认展开；非当前电脑才用 `CX / PI` 头像组表达。Human 看过实物仍要当前卡也挂，2.4.1 补。
- 2.4.1 已知两条：某天第一条恰好是空消息时日期分隔条被吞；危险区「忘记这台电脑」用了 `Trash2`（语义像删数据），换 `LogOut`。

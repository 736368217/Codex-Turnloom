## 排版：根因是 lineHeight 写成了无单位数值

`style={{ fontSize: 13, lineHeight: 19 }}` 在 React 里是**无单位**的，浏览器按倍数解释：
19 × 13px = **247px 行高**。所以：

- 设置页「当前已是 x.y.z，无需更新」那一行单独占 247px → 卡片被撑到 350px，中间一片空白；
- 首页空态说明 `lineHeight: 18` × 12px = 216px 同理。

改成 `'19px'` / `'18px'` 后实测：

```
设置页更新卡：body 305 → 77，card 350 → 122
会话页空态卡：card 111（图标 26 / 标题 21 / 说明 24）
```

EmptyState 同时改成固定类 `.tl-empty-title/.tl-empty-desc` + `height:auto !important`，不再受祖先 flex 拉伸影响。

## 会话列表：按项目 / 按时间

- 顶部两段切换：**按项目**（默认）/ **按时间**；

## 启动闪连接页 & 自动检查更新

- `hydrateSession()` 前移到模块初始化（同步读），并加 260ms 冷启动宽限：这段时间只画底色，绝不渲染连接页；
- `AppShell` 挂载时查一次 `/api/app/update-public`，有新 `versionCode` 就弹「发现新版本 x.y.z / 稍后 / 去更新」。

实测更新弹层：`shown=true / 标题=发现新版本 9.9.9 / 按钮=[稍后,去更新]`（用假版本号触发）。

## 未验证完的一项（如实说明）

冷启动「不闪连接页」在浏览器夹具里仍采样到 2 次（25ms 一次），原因是夹具注入的配对种子不被 `hydrateSession` 接受（`bootSaved=null`），
于是 260ms 宽限期后仍然按「未配对」渲染了连接页，等网络校验回来才进工作台。真机上配对写在原生安全存储里，走的是 `bootSaved` 分支（该分支不渲染连接页）。
这一条需要真机冷启动录屏或逐帧截图才能最终确认，我不把它算作已验证。

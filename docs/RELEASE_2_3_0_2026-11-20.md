# 2.3.0 — 运行中也能排队（2026-11-20）

App `2.3.0`（versionCode `98`）· 电脑端服务需同步升级（新增队列接口）

这一版补齐对话里最基本的**排队**，并把 2.2.6 → 2.2.8 的界面改动一并发布。
上一次 GitHub Release 停在 2.1.7，中间 2.2.x 的包只走过更新通道；从这一版起每次发版都推 `main` 并建 Release。

## 排队（本轮主线）

- **运行中发送 = 入队**：会话正在跑时按发送，消息进队列而不是被拒；顶部出现队列条「N 条排队」。
- **队列抽屉**：单条详情、取回编辑、上移 / 下移 / 置顶、重试、删除；失败条目挡住后面的顺序，不会静默跳过一个坏消息。
- **停止即暂停**：运行中点停止 → 队列暂停，可恢复；恢复时等服务端 `thinking` / `interactionRequired` 结束再发下一条，避免双发。
- **附件一起排队**：图片按原始字节保存（PNG 仍是 PNG），服务重启后队列里的图仍可发；单条 data URL 上限 1.5 MB。
- **插队 / 优先下一条**：PI 入口下「优先下一条」把队首提为下一条发送。
- **服务端**：`GET /api/queue/status` 返回 `queueCapabilities{turnSteer,queueFiles}` 与 `queuePaused`；新增重排、恢复、队列文件持久化；`interrupt` 之后队列自动暂停。

## 2.2.6 → 2.2.8 一并发布的改动

- **三页信息架构**：会话 / 设备 / 设置；监控页并入会话页顶部运行条。
- **设备页**：电脑 → 平台（Codex / PI-Desktop）→ 入口（harness）三层；当前电脑恒展开，切换失败保留原状态并给原因。
- **运行条**：44px 命中带，不再借用上方分段控件的点击区。
- **连接页**：插图 + 极淡光晕，矮屏（≤540px 可用高度）自动隐藏，扫码按钮保持在首屏。
- **图标**：全站统一 Lucide，尺寸 {14,16,20,22}，线宽 2。

## 安装

- **覆盖安装**即可：同一签名证书 `2F:EB:63:C5:…:FA:9C`，`versionCode 98 > 97`。
- 电脑端服务要一起升级（这一版新增 `/api/queue/status` 等接口）；附件里的 `turnloom-2.3.0-server.zip` 是 Windows 服务升级包。
- 校验：`sha256sum -c` 对应 `.sha256` 文件，或比对 `latest.json` 里的 `sha256`。

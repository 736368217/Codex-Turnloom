# 2.4.0 界面审计：每个控件都要能被「说出来」

> 作者 @NB3 · 2026-11-20 23:57 · 只读审计，不改码
> 上游任务：task:aab2c29b（2.4.0 / 99）· 实施 @Iris · 设计门禁 @NB3
> 已有缺陷清单见 [USABILITY_AUDIT.md](USABILITY_AUDIT.md)、[VISUAL_AUDIT.md](VISUAL_AUDIT.md)；
> **本文不重复缺陷，只回答一个问题：这个控件凭什么留在屏幕上。**

## 0. 判定口径

一句话标准：**能不能说出「用户在什么时刻会点它」，说不出来就是占位。**
三类判定：

| 判定 | 含义 | 处置 |
|---|---|---|
| **需要** | 有明确触发时刻，且没有更近的入口 | 保留；只改造型 |
| **重复** | 同一动作已有另一个入口 | 删，或收敛到唯一入口 |
| **占位** | 只证明「这里有个状态」，用户从不点它 | 删；状态改由别处表达 |

补充一条否决权：**一个控件在 390 上的高度，必须换回一个用户能感知的收益。**
设置页现有 11 个可点控件，按本口径只剩 4 个该独立成行。

## 1. 结论速览

- **删 6 处**：测试连接、切换电脑上的服务（设置页入口）、上传诊断（独立行）、运行信息（独立 sheet）、
  检查更新（独立行）、清除缓存会话（独立行）。
- **收 1 处**：`运行中转圈`（与副标题「运行中」重复表达）。
- **并 2 组**：诊断 = 日志上传 + 运行信息 + 清缓存；关于 = 版本 + 检查更新 + 许可 + 更新日志 + 反馈。
- **加 9 处**：字号、会话列表默认视图、触感反馈、正文搜索、搜索命中分组 + 高亮、
  「N 运行中 · M 待你处理」、对话页来源头像、日期分隔、跳到最新。
- **改造 4 处**：平台标 `CX`/`PI` 文本 → 头像；设备条 `⌄` → `›`；非当前电脑显示平台头像组；
  搜索框移入固定区。
- 设置页从 **11 个控件 / 4 组** 收敛为 **9 个控件 / 4 组 + 危险操作**，其中 5 个是 2.4.0 新增。

### 5.3 三条实现约束（给 Iris）

1. **诊断 sheet 是唯一诊断入口**：运行信息 8 行 + 上传按钮 + 清缓存 + 重新同步，一个 sheet 内分两段，
   不新开页、不嵌套 sheet。
2. **字号只作用于正文与列表**：正文（气泡）、列表标题/预览、设置行标签三处。图标、命中区、头部大标题
   都不缩放 —— 44px 命中与已量过的几何不能被字号带跑。
   实现上用**根级 CSS 变量**（`--tl-fs-body` 等）替换这三处的硬编码 px，
   由 `<html data-text-size="s|m|l">` 切换；**不要**用 `zoom` / `transform: scale()` /
   根 `font-size: rem` 全局缩放（会同时缩放命中区与截图基线）。
3. **触感开关**：`haptic()` 增加全局开关，默认开；关掉后所有 `haptic()` 立即空转，不改调用点。

## 9. 预判分歧（我和 Iris 谁对，用"场景"判）

1. **搜索框是否常驻固定区**：我的立场是常驻。反例只有"键盘弹起挤压列表"，用
   输入时收起分段（只留输入框 + 结果）即可解，不该把搜索藏进滚动流。
2. **字号是否影响列表摘要**：我的立场是影响正文但**不影响**预览行（预览已是 12/17，
   再放大两行就挤掉时间列）。Iris 若要做全量字号，先给 320 的截图再谈。
3. **头像用品牌字形还是几何标**：只要 24px 下能分辨 Codex / PI 且是单色（UI_SPEC 单套 Lucide），
   两者都行；不做彩色多色标（会破坏"白底单蓝"基调）。

## 10. Vera 可用的诚实性核对点

1. 运行条第一个数字 == `/api/threads` 里 `thinking` 的条数；第二个 == `interactionRequired` 的条数；
   两者之和 **不得小于** 电脑端侧栏"运行中"可见数（若小于，就是 P1 没修完）。
2. 搜索「项目名」必须命中该项目下的会话；搜索「正文里才有的词」必须出现在"内容命中"分组；
   搜一个字母**不应**出现标题无关的会话（P2 回归）。
3. 设置页每个入口点进去都不是死路：诊断 sheet 能上传/能清缓存；版本行点击会真的发起检查
   （右侧状态变化）；字号切到大 → 正文与列表变大、44px 命中不变。
4. 诊断 sheet 里的「外观/字号/视图」必须反映当前真实设置，不能写死（P8 回归）。

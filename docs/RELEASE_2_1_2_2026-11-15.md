## 同请求 ID 的 409 重试

实测发现：在首轮刚结束、门面仍报告运行中时发送下一轮，服务明确在调用宿主前拒绝，但幂等缓存仍保留该失败 5 分钟，导致草稿稍后同 ID 重试继续得到旧 409。

修复只给两处“发送前仍在运行”闸门标记 `sendNotStarted`，这类明确未发送的失败移出缓存；成功、超时和可能已执行的失败仍保持去重。定时器只能删除自己对应的缓存项。回归证明同 ID 在空闲后可成功，成功后不重复；未知执行结果不能重放。

说明与边界

  • 完整 mobile-app Gradle release 仍受 Windows 长路径 / CMake / Ninja 限制；设备验收使用当前源码重新编译的 Hermes bundle 热替换到已验证原生壳中并重新签名。
  • 截图数据全部来自隔离文档 fixture，不含真实访问码、二维码、账户或私人会话。
  • 服务内置网页是兼容入口；报告中的相对路径副本仅用于静态视觉复现，不改变产品源码的 HTTP 路由。
  • 验收结束已卸载隔离测试包、移除 adb reverse、停止 fixture、恢复字体缩放并释放 MuMu phone 租约。

## 重点变化

### PI-Desktop：普通收发不再依赖人坐在电脑前

- 手机端按会话真实模型解析（`wbfd/deepseek-v4.1-flash` ↔ 裸 `deepseek-v4.1-flash`），不再把目录默认模型当成用户选择。
- 普通发送**不带 `model`**；服务端取会话当前 `provider/model/thinking`，桥不再调用 PI 的 dangerous `session/configure`。
- 真机验收：窗口失焦、无人操作，连续 3 条普通消息 3/3 回复，`session/configure` delta = 0，0 个原生弹窗；`sessions` 的 provider/model/thinking 行前后不变。
- 安装布局、固定访问码、模型目录并集与桥回归测试一并补齐；访问码只在 `%USERPROFILE%\.pidesktop-turnloom\access-code.txt`。

### 视觉与易用性

- TabBar 改为手写 `<nav role="tablist">` + 4 个 `role="tab"` 按钮，恢复 56px + 安全区的毛玻璃栏，不再让列表从栏里透出，也不再被压住。
- 会话页默认「按时间」，首屏直接看到最近会话；「按项目」分组默认展开，修掉“第一次点击不展开”。
- 监控页的「查看 / 停止」改为真实停止按钮（44×44、停止中 spinner、失败原因可见）。
- 输入舱、模型触发键、审批决定、思考折叠头、新建任务等触控目标统一到 ≥44px。
- 会话气泡 15/22（字号/行高），列表行补充时间戳；未配对时不再隐式外联公网更新域。
- 首屏机器名/服务名/地址去重：机器名只出现一次，副标题显示服务类型与 `host:port`。

### 后端与构建

- 审批路由 400/403/404/409 全部带稳定 `code`（`approval_identity_required`、`approval_request_unavailable` 等），`error` 文本保持兼容；`--backend http` 的发现路由由本地回答，不再 501。
- 修复 `--machine-token` 与 `--token` 不同值时配对失败。
- `scripts/build-single-app.ps1` 自动探测仓库根 / Android SDK / build-tools / JDK / keystore；新增 `-BuildType debug` 与 `-HttpProxy`；不再写死 `D:\pi11`。
- 干净检出 `npm run verify:ci` 通过；冻结归档缺失的测试显式 skip。

## 已知限制

- 本轮 APK 是 debug 签名测试包；正式分发需要独立 release keystore 与 `apksigner` 流程（脚本已支持）。
- PI 的审批、归档、删除、计划确认仍属桌面 dangerous 操作；不同 PI 版本可能要求在桌面确认。普通消息收发不受影响。
- 真实 Codex Desktop 审批“成功”路径只到函数级 fixture，未在本轮用真实桌面审批弹窗复验。
- iOS Safari 真实安全区未在本机验证；使用 CDP 模拟 47/34。
- PI 数据里留有若干 `New task` 测试会话，是否删除由使用者决定。

## 安装

1. 电脑端更新 `server.js` 与 `third-party/turnloom-pidesktop` 桥；重启 PI-Desktop。
2. 手机安装 APK；地址填 `http://<电脑局域网 IP>:8799`，访问码从 `%USERPROFILE%\.pidesktop-turnloom\access-code.txt` 读取。
3. 详细步骤见 `docs/PI_DESKTOP.zh-CN.md`。

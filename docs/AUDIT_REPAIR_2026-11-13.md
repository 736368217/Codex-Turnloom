## 审批边界

- 两条命令相同但 request ID 不同的审批不再按命令合并。React 卡片键包含会话、request ID 和详情摘要，首条完成后后续卡片不会继承其本地状态。
- 服务端拒绝缺标识、错类别、错摘要、跨会话、过期、已解决以及并发重复决定；成功后记录已解决请求，IPC 已有后续决定事件的请求也不可再次批准。
- 主机提供 availableDecisions 时只接受其列出的决定；“允许本次会话”明确显示其范围，不降级为一次批准。
- IPC 超时或未知错误不会通过另一方法/别名自动重放。只有明确“不支持方法/决策”的错误才尝试既有兼容路径。
- HTTP backend 在转发前也校验完整身份字段；最终执行仍由实际宿主确认。旧客户端缺少 detailsHash 的决定会被拒绝，需要同步更新客户端与服务。

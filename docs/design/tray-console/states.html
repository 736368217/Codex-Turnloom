服务状态与托盘图标

控制台在任何状态下都要给出明确反馈，并保留一个可以继续操作的动作。

设计稿 · 状态矩阵
State 01 · Starting

启动中

正在启动· 等待健康检查

已拉起 Node 服务进程，正在等待 /api/health 返回。通常持续 1–3 秒。

托盘图标：琥珀色 + 旋转角标
菜单：显示「取消启动」
State 02 · Running

运行中

服务正常· 隧道已连接

本机服务与 SSH 隧道均正常，手机端可以访问。托盘图标为品牌蓝并带绿色角标。

菜单：打开控制台 / 重启 / 停止
窗口：显示完整概览与配对信息
State 03 · Degraded

部分可用

隧道断开· 第 2 次重试

本机服务正常，局域网仍可访问；公网 SSH 隧道中断，正在按退避策略自动重连。

建议：检查服务器与网络
下一次重试：8 秒后
State 04 · Stopped

已停止

服务未运行· 手机端不可访问

服务由用户手动停止，或控制台退出后保持停止状态。数据与配置不会丢失。

托盘图标：灰色无角标
菜单：启动服务 / 打开上次日志
State 05 · Error

启动失败

端口被占用· 未启动

端口 8787 已被其他程序监听，服务无法绑定。控制台给出原因和可执行的修复动作。

错误码：EADDRINUSE
占用进程：node.exe · PID 10492

判定顺序

状态以事实为准

  1. 进程是否存活（PID 可查）
  2. 端口是否监听（8787）
  3. /api/health 是否返回 200
  4. /api/debug/events 的 IPC 连接
  5. SSH 隧道进程是否存活
错误处理

给原因，也给下一步

EADDRINUSE更换端口 / 结束占用进程
CODEX_HOME重新选择 Codex 数据目录
SSH key重新选择密钥 / known_hosts
node指定 node.exe 路径
托盘交互

不打开窗口也能完成大部分操作

左键单击打开 / 收起主窗口
右键单击状态菜单（启停 / 配对 / 设置）
鼠标悬停机器名 + 当前状态 + 运行时长
双击与左键单击一致

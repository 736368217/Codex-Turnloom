# 00 一页纸速览（V2 · Loom Studio 升级版）

- **版本**：V2.0（2026-10-23）
- **定位**：Codex Desktop 的私有、自托管移动工作台（Android 原生外壳 + WebView 工作区）
- **核心标语**：离开电脑时，一眼看清 Codex 在做什么，单手稳妥接住它。

## 1. V2 六大核心升级亮点

| 维度 | V1 原版痛点 | V2（Loom Studio）升级方案 |
| --- | --- | --- |
| **色彩统一性** | 操作蓝 `#0066CC` 与旧版青绿 `#1F6F62`、暖黄灰 `#F6F5F2` 混杂打架 | 全局统一为 **织机冷灰 `#F4F5F8` + 纯白 `#FFFFFF` + 唯一操作蓝 `#0066CC`**，彻底清除青绿残留 |
| **状态可见性** | “思考中 / 需要处理”仅是顶栏 12px 灰色文字，极易忽略 | 顶栏前置 **高对比语义状态胶囊（Status Pill）**：`● 思考中 · 01:18`（珀橙）、`● 待确认权限`（珊瑚红） |
| **顶栏视觉焦点** | 右上角工具开关为实心蓝圆 + `🔧` Emoji，与发送按钮抢焦点 | 改为 **40×40dp 线性扳手图标按钮**，开启态用浅蓝底 `#E8F2FF` + 右上角 6px 蓝点，归还发送按钮唯一焦点 |
| **输入与运行控制** | 底部一行塞入 6 组控件，模型名被挤断，`排队/插入` 含义模糊 | 升级为 **一体式输入工作舱**；运行中在输入框上方独立展开 **`排队（完成后发） | 插入（立即打断）`** 控制条 |
| **权限审批卡片** | 红底配青绿/棕黄 32dp 小按钮，易误触且路径不突出 | 升级为 **安全决策卡**：白底红顶边 + **等宽代码路径沙盒框** + **44dp 高防误触三态按钮**（允许本次 / 始终允许 / 拒绝） |
| **消息流与设备页** | 每条消息带 3 层元信息与多余“已发送”；设备列表缩进参差 | 角色、耗时与时间 **合并为单行轻量眉标**；工具记录改为 **紧凑可折叠步骤卡**；设备页改为 **独立悬浮卡 + 最近任务直达** |

## 3. V2 核心视觉令牌速查

- **背景与表面**：页面底色 `#F4F5F8` · 主卡片/助手气泡 `#FFFFFF` · 次级填充 `#EEF0F5` · 边框 `#E2E5EC`
- **文字层级**：主文字 `#111827` · 次级正文 `#4B5563` · 元信息 `#6B7280` · 占位符 `#9CA3AF`
- **唯一主操作色**：操作蓝 `#0066CC` · 按下态 `#0052A3` · 浅蓝选中/用户气泡 `#E8F2FF` · 浅蓝边框 `#C2DCFF`
- **语义状态色**：
  - 在线 / 已就绪：文字 `#15803D` · 圆点 `#16A34A` · 胶囊底 `#DCFCE7`
  - 运行中 / 思考中：文字 `#B45309` · 圆点 `#D97706` · 胶囊底 `#FEF3C7`
  - 待审批 / 离线 / 错误：文字 `#B91C1C` · 圆点 `#DC2626` · 胶囊底 `#FEE2E2`
- **四档统一圆角**：`8px`（小标签/沙盒框） · `12px`（按钮/导航块/输入项） · `16px`（气泡/设备卡/输入舱） · `999px`（胶囊/主按钮/圆形发送键）

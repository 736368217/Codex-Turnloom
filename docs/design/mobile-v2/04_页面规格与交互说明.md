# 04 页面规格与交互说明（V2 升级版）

> 基准画布：Android 390×844dp（@2x 渲染尺寸为 780×1688px）。
> 全部页面高保真视觉效果请对照 `screens/00_全部页面总览.png` 及 `01`–`08` 单页图。

## 4.1 S01 电脑选择 · 空状态（对应 `screens/08_电脑选择_空状态.png`）

- **原生顶栏（56dp）**：左侧品牌 Logo（28dp）+ `Codex-Turnloom`（18sp/700）；右侧 `指引` 与 `＋ 添加` 胶囊按钮（高 36dp，热区 44dp，背景 `#EEF0F5`）。
- **页面标题区**：`连接你的第一台电脑`（25sp/700，`#111827`）+ 副标题说明（13.5sp，`#6B7280`）。
- **中心配对引导卡（22dp 圆角白卡）**：
  - **顶部连接拓扑图示**：左侧电脑图标块（54×54dp 浅蓝底）+ 中间连接线 `● ── 局域网 / HTTPS ── ●` + 右侧手机图标块（54×54dp），直观解释“手机直连电脑”的工作模型。
  - **文案**：标题 `扫描电脑端设备码开始`（18.5sp/700）+ 说明文案。
  - **双按钮栈**：主按钮 `扫描设备二维码`（48dp 高全圆角，`#0066CC` 实心蓝）+ 次按钮 `手动输入电脑地址与访问码`（46dp 高全圆角，`#EEF0F5` 浅灰底）。
- **底部隐私承诺**：`🔒 无需注册云端账号 · 电脑信息与访问码只保存在本手机`（11.5sp 居中）。

## 4.2 S02 电脑选择 · 列表（对应 `screens/01_电脑选择.png`）

- **独立悬浮设备卡（取代 V1 挤在一起的分割线列表）**：
  - 每台电脑为一张独立的 `16dp` 圆角白卡，间距 `11dp`，内边距 `14dp`。
  - **在线主力设备高亮**：边框采用 `1.5px solid #C2DCFF`，左侧配 `44×44dp` 浅蓝底电脑图标容器；离线/检测中设备配浅灰底图标容器。
  - **卡片首行**：左侧电脑名（16sp/700，单行不换行）+ 右侧状态胶囊（`● 在线 · 1 运行中` 翠绿胶囊 / `● 离线` 珊瑚红胶囊 / `● 正在检测` 冷灰胶囊）。
  - **卡片次行与末行**：备注（12.5sp `#4B5563`）+ 等宽字体地址与延迟（`office.example.com · 延迟 12ms`，11.5sp `#6B7280`）。
  - **右侧操作**：`⋮` 更多菜单按钮（44×44dp 热区）+ `›` 进入箭头。
- **最近活跃任务直达横幅**：
  - 位于设备列表下方，展示 `⚡ 最近活跃任务（办公室电脑）：评估手机端设计方案 · 正在思考中 (01:18)` + 右侧 `直达 →`，点击直接进入该对话工作台。
- **底部添加面板**：独立白卡包裹，`扫描设备二维码` 与 `＋ 手动输入` 双按钮并排（高 46dp），底部附带 Keystore 加密说明。

## 4.3 S06 访问码门禁（对应 `screens/07_访问码.png`）

- **背景**：柔和径向冷灰微光背景 `radial-gradient(circle at 50% 20%, #E8F2FF 0%, #F4F5F8 65%)`。
- **卡片头部**：左侧 48×48dp 品牌 Logo + 右侧 **当前目标电脑在线胶囊**（`● 办公室电脑 · 在线`），让用户清楚知道自己正在解锁哪台电脑。
- **标题防断行优化**：Eyebrow `PRIVATE MOBILE WORKSPACE`（11sp/700）+ 标题 `Codex-Turnloom`（**24sp/700，`letter-spacing: -0.02em`，`white-space: nowrap`**，彻底解决 V1 断成两行的问题）。
- **表单与提交**：带 `设备访问码` 标签的 50dp 高聚焦输入框（右侧带显示/隐藏眼睛按钮）+ `在这台手机上记住访问码（Keystore 加密）` 复选行 + 48dp 高 `进入工作区 →` 主按钮。

## 4.4 S07 对话列表抽屉（对应 `screens/02_对话列表.png`）

- **抽屉顶部**：显示当前连接的电脑名（如 `办公室电脑`）与实时在线状态 `● 在线 · 12 个对话`，右侧配 36×36dp（44dp 热区）圆角收起按钮 `<`。
- **搜索与新建行**：左侧 40dp 高圆角搜索框 `搜索对话或项目...` + 右侧 40dp 高 `#0066CC` 实心蓝 `＋ 新对话` 按钮。
- **对话列表项（高 ≥ 58dp，圆角 12dp）**：
  - 第一行：对话标题（14.5sp/600，选中态深蓝 `#004494`）。
  - 第二行：**状态胶囊**（`● 运行中 · 01:18` / `● 等待审批` / `● 已结束`）+ 消息条数或 `🔔 提醒已开` 蓝色微标签。

## 4.5 S08 对话工作台（对应 `screens/03_对话工作台.png`）

- **顶栏（`.ws-header`）**：
  - 左上：40×40dp 圆角抽屉按钮（浅灰底 `#EEF0F5`）。
  - 中部：第一行对话标题（16sp/700）；第二行 **前置状态胶囊** `● 思考中 · 01:18` + `18 条内容 · 主力机`。
  - 右上：两个 40×40dp 线性图标按钮（**工具记录开关** + **刷新**）。工具开关开启时为浅蓝底 `#E8F2FF` + 蓝扳手图标 + 右上角 6px 蓝点，绝不抢夺发送按钮的视觉权重。
  - **目标条（`.goal-bar`）**：左侧 3px `#0066CC` 蓝色竖线 + `目标` 浅蓝标签 + 单行目标文本 + 右侧 `进行中 ▸`。
- **消息流（`.msg-stream`）**：
  - **用户消息**：右对齐，上方单行 `你 · 16:18`（正常已发送不显示多余的“已发送”文字，仅在发送中/失败/排队时显示状态），气泡为 `#E8F2FF` 浅蓝底 + `#D0E4FF` 边框。
  - **Codex 消息**：左对齐，上方单行 `[Logo] Codex · 耗时 12s · 16:19`，气泡为纯白底 + `#E2E5EC` 边框。
  - **工具步骤卡（`.tool-step-card`）**：紧凑白卡，首行左侧 `[读取文件]` 灰底标签 + 等宽路径 `public/styles.css`，首行右侧 `0.8s · 16:19 ▾`，次行展示精简结果摘要。
  - **实时思考指示卡（`.thinking-card`）**：左侧 3px 琥珀橙竖线 + 呼吸圆点 + 当前动作描述与已运行时长。

## 4.6 S09 权限审批（对应 `screens/04_权限审批.png`）

- **安全决策卡片（`.approval-card`）**：
  - 白底卡片，四周 `1.5px solid #FCA5A5` 浅红边框，**顶部 4px `#DC2626` 警示红条**。
  - 首行：`⚠️ 需要处理 · 等待确认` 浅红胶囊 + 右侧时间戳。
  - 标题：`允许 Codex 写入以下目录吗？`（15sp/700）。
  - **目标路径沙盒框（`.sandbox-box`）**：`#F8FAFC` 灰底 + `#CBD5E1` 边框，内含 `目标路径 (WRITE ACCESS)` 微标与等宽加粗路径 `~/Documents/Design-Handoff`。
  - **三列防误触大按钮组（高 44dp，圆角 12dp，间距 8dp）**：
    1. **允许本次**（副标 `是 (Yes)`）：实心操作蓝 `#0066CC` 白字，主视觉焦点。
    2. **始终允许**（副标 `一直是 (Always)`）：浅蓝底 `#E8F2FF` + `#0066CC` 蓝字。
    3. **拒绝**（副标 `否 (No)`）：浅灰底 `#EEF0F5` + `#B91C1C` 深红字。

## 4.7 S10 运行中排队与插入（对应 `screens/05_运行中排队.png`）

- **候发队列面板（`.queue-panel`）**：
  - 位于输入区上方，采用浅蓝灰底 `#F8FAFC` + 浅蓝边框 `#C2DCFF`（彻底替换旧版青绿色）。
  - 头部：`⏳ 候发队列（2 条）· 任务完成后自动发送` + 右侧 `清空 ×`。
  - 队列项：白底小卡，左侧显示 `#1 排队中` 与单行消息内容，右侧三个紧凑按钮：`⚡ 插入`（浅蓝高亮）、`编辑`、`取消`。
- **运行态发送方式控制条（`.mode-strip`）**：
  - 独占一行位于输入框正上方，左侧标签 `发送方式`，右侧分段控制器：`[ 排队（完成后发） | 插入（立即打断） ]`，选中项采用 `#0066CC` 实心蓝高亮。
- **一体式输入工作舱（`.composer-pod`）**：
  - 上方为多行输入框，下方左区为 `[GPT-5.6 | 中 ▾]`、`[@ 插件]`、`[/ 技能]` 胶囊（`white-space: nowrap`），下方右区为 `[+]` 附件、`[■]` 停止（浅红底红框）、`[↑]` 发送（实心蓝圆）。

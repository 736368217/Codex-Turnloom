## 1. 给 Coding AI 的代码改造清单（精准对应 `public/styles.css` & `public/index.html`）

请在不破坏现有 JS 事件绑定 ID（如 `#authGate`, `#sidebarToggle`, `#toolToggle`, `#composerForm`, `#followUpMode`, `#queueStatusBar` 等）的前提下，按以下 6 个模块执行代码升级（可直接参考 `reference/v2-styles.css` 与 `reference/v2-index.html`）：

### 任务 M1：替换全局 `:root` 设计令牌，彻底清除遗留青绿与暖灰
1. 打开 `public/styles.css`，将顶部 `:root` 中的暖灰/青绿变量全部替换为 V2 冷灰与单一操作蓝体系：
   - `--bg: #F4F5F8;`
   - `--panel: #FFFFFF;`
   - `--panel-soft: #EEF0F5;`
   - `--border: #E2E5EC;`
   - `--text: #111827;`
   - `--text-secondary: #4B5563;`
   - `--muted: #6B7280;`
   - `--accent: #0066CC;`
   - `--accent-pressed: #0052A3;`
   - `--accent-soft: #E8F2FF;`
   - `--accent-border: #C2DCFF;`
2. 全局搜索 `public/styles.css` 中的 `#1f6f62`、`#77a99d`、`#dcece8`、`#f1f7f5`、`#c9d8d3`、`#e5e1d9`、`#f7f6f2`，将其全部收敛至上述语义变量，确保全界面 **零青绿/暖棕残留**。

### 任务 M2：重构顶栏（`.conversation-header`）、工具开关（`#toolToggle`）与目标条（`#goalPanel`）
1. **前置状态胶囊**：在 `#threadMeta` 中，将任务状态（`思考中` / `需要处理` / `已结束`）渲染为带圆点的语义胶囊 `.status-pill`（运行中 `#FEF3C7` 底 `#B45309` 字；待处理 `#FEE2E2` 底 `#B91C1C` 字；已结束 `#DCFCE7` 底 `#15803D` 字）。
2. **工具开关降噪**：将 `#toolToggleLabel` 中的 `🔧` Emoji 替换为线性扳手 SVG 图标；默认态背景为 `--panel-soft`（`#EEF0F5`），选中态（`input:checked + span`）背景改为浅蓝 `--accent-soft`（`#E8F2FF`）、图标色 `--accent`（`#0066CC`），并在右上角增加 6px 实心蓝点伪元素，**禁止使用实心深蓝圆背景**。
3. **目标条统一为操作蓝**：将 `.goal-panel` 左边框改为 `3px solid var(--accent)`，背景 `#F8FAFC`，圆角 `8px`，状态文字色改为 `var(--accent)`。

### 任务 M3：重构输入区（`.composer`）与运行中发送方式条（`#followUpMode`）
1. **运行中发送方式独立成行**：在 DOM 或 Flex 布局中，将 `#followUpMode` 置于 `#composerInput` 上方（宽度 100% 独立成条），左侧显示标签 `发送方式`，右侧分段按钮文案更新为 `排队（完成后发）` 与 `插入（立即打断）`，选中态采用 `--accent`（`#0066CC`）实心蓝底白字。
2. **一体式输入工作舱**：将 `#composerInput` 与底部 `.composer-actions` 视觉整合在 `16px` 圆角、白底、带聚焦光晕的容器内。
3. **底部胶囊防换行**：为 `.model-summary`、`.plugin-picker-button`、`.skill-picker-button` 强制设置 `white-space: nowrap; height: 32px; border-radius: 999px; background: var(--panel-soft);`，确保在 360dp–390dp 下模型名与插件/技能按钮绝不折成两行。

### 任务 M4：升级权限审批卡片（`.bubble.interaction` & `.approval-actions`）
1. **卡片容器**：背景设为 `#FFFFFF`，边框 `1.5px solid #FCA5A5`，顶部边框 `4px solid #DC2626`，圆角 `16px`，阴影 `0 8px 24px rgba(220, 38, 38, 0.08)`。
2. **路径/命令沙盒化**：审批请求中的路径或命令文本使用 `.sandbox-box`（`background: #F8FAFC; border: 1px solid #CBD5E1; border-radius: 8px; font-family: monospace; padding: 9px 12px;`）高亮包裹。
3. **44dp 防误触三态按钮**：`.approval-actions` 改为 `display: grid; grid-template-columns: 1.2fr 1.2fr 0.9fr; gap: 8px;`，按钮高度 `44px`，圆角 `12px`：
   - “是（允许本次）”：`background: var(--accent); color: #FFFFFF;`
   - “一直是（始终允许）”：`background: var(--accent-soft); border: 1px solid var(--accent-border); color: var(--accent);`
   - “否（拒绝）”：`background: var(--panel-soft); border: 1px solid var(--border); color: #B91C1C;`

### 任务 M5：升级候发队列面板（`#queueStatusBar`）与消息流（`.message-list`）
1. **候发队列面板**：`.queue-status-bar` 背景改为 `#F8FAFC`，边框 `1px solid var(--accent-border)`，圆角 `16px`；内部每条队列项为独立白底小卡（`8px` 圆角），“转为插入”按钮使用浅蓝底蓝字高亮。
2. **消息元信息精简**：合并角色名称、处理耗时与时间戳为气泡上方的单行眉标；当用户消息状态为正常“已发送”时，隐藏冗余的“已发送”文字，仅在“发送中 / 发送失败 / 排队中”时显示状态。

### 任务 M6：升级访问码卡片（`#authGate`）与 Android 原生电脑选择页
1. **访问码标题防断行**：`.auth-card` 圆角设为 `22px`，`.auth-card h2` 字号设为 `24px`，`letter-spacing: -0.02em`，`white-space: nowrap`，确保 `Codex-Turnloom` 在 360dp–390dp 下始终单行优雅显示。
2. **Android 原生电脑选择页（`MainActivity`）**：将电脑列表项渲染为独立的 `16dp` 圆角白底卡片（间距 `11dp`），左侧配 44×44dp 设备图标块，名称右侧配状态胶囊（`● 在线` / `● 离线` / `● 正在检测`），列表下方可展示最近活跃任务快捷横幅。

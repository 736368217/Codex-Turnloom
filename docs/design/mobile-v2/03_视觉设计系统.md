# 03 视觉设计系统（V2 · Loom Studio 规范）

## 1. 视觉风格定义

**Loom Studio（极简织机工作台）**：以精密仪器般的冷调中性表面为基底，配合唯一的电光操作蓝（`#0066CC`）与高辨识度语义状态胶囊，营造安静、大气、专业的移动工程控制面。

## 2. 色彩系统（Color Tokens）

### 2.1 基础表面与文本色（Light Mode 默认）

| Token 名称 | CSS 变量建议 | 色值 | 对比度 / 用途说明 |
| --- | --- | --- | --- |
| `color.base.bg` | `--bg` | `#F4F5F8` | 全局工作区背景、电脑列表底色（通透冷灰，取代旧版暖灰 `#F6F5F2`） |
| `color.base.panel` | `--panel` | `#FFFFFF` | 卡片、Codex 消息气泡、输入工作舱、顶栏基底 |
| `color.base.panelSoft` | `--panel-soft` | `#EEF0F5` | 次级按钮底色、胶囊背景、搜索框底色、默认图标按钮底 |
| `color.base.border` | `--border` | `#E2E5EC` | 卡片外边框、分割线（1px 实线） |
| `color.base.borderSubtle` | `--border-subtle` | `rgba(15,23,42,0.07)` | 顶栏内嵌按钮、轻量容器微边框 |
| `color.base.text` | `--text` | `#111827` | 主标题、消息正文、核心数值（与白底对比度 17.4:1） |
| `color.base.textSecondary` | `--text-secondary` | `#4B5563` | 副标题、电脑备注、工具摘要、次要按钮文字（对比度 7.5:1） |
| `color.base.muted` | `--muted` | `#6B7280` | 时间戳、耗时、地址、底部隐私说明（对比度 4.8:1，符合 WCAG AA） |
| `color.base.placeholder` | `--placeholder` | `#9CA3AF` | 输入框占位符文字 |

### 2.2 唯一主操作色（Single Action Accent）

> **铁律**：全应用禁止出现除 `#0066CC` 以外的第二种非语义强调色。旧版遗留的 `#1F6F62`（青绿）、`#77A99D`、`#DCECE8` 必须全部替换为以下操作蓝令牌。

| Token 名称 | CSS 变量建议 | 色值 | 用途说明 |
| --- | --- | --- | --- |
| `color.action.accent` | `--accent` | `#0066CC` | 发送按钮、扫码主按钮、审批“允许本次”、排队/插入选中态、目标条左竖线 |
| `color.action.accentPressed` | `--accent-pressed` | `#0052A3` | 主按钮按下/激活态 |
| `color.action.accentSoft` | `--accent-soft` | `#E8F2FF` | 用户消息气泡、选中对话行、工具开关开启态底色、“始终允许”按钮底色 |
| `color.action.accentBorder` | `--accent-border` | `#C2DCFF` | 选中项边框、用户气泡边框、候发队列面板外框、在线主力机高亮框 |
| `color.action.focusRing` | `--focus-ring` | `rgba(0,102,204,0.14)` | 输入框与按钮聚焦外发光（`0 0 0 3px`） |

### 2.3 语义状态色（Semantic Status Colors）

所有状态胶囊均采用 **「6px 实心圆点 + 加粗状态词 + 柔和浅底」** 组合，绝不仅靠颜色表达状态：

| 状态语义 | 圆点色 | 文字色 | 胶囊背景色 | 适用场景 |
| --- | --- | --- | --- | --- |
| **在线 / 已结束 / 就绪** | `#16A34A` | `#15803D` | `#DCFCE7` | 电脑在线、对话任务已完成 |
| **运行中 / 思考中** | `#D97706` | `#B45309` | `#FEF3C7` | Codex 正在思考、工具执行中 |
| **等待审批 / 离线 / 危险** | `#DC2626` | `#B91C1C` | `#FEE2E2` | 权限请求待确认、电脑离线、停止按钮、删除操作 |
| **正在检测 / 未知** | `#64748B` | `#475569` | `#F1F5F9` | 电脑连接检测中、工具步骤类型标签 |
| **系统提示 (Notice)** | `#D97706` | `#92400E` | `#FFFBEB` | 提示条背景（配 `#FDE68A` 边框） |

### 2.4 深色模式令牌（Dark Mode 扩展）

- 页面背景 `--bg`: `#0B0F17`
- 卡片表面 `--panel`: `#161C28`
- 次级表面 `--panel-soft`: `#1E2636`
- 边框 `--border`: `#2A3447`
- 主文字 `--text`: `#F3F4F6` · 次文字 `--muted`: `#9CA3AF`
- 操作蓝 `--accent`: `#3B82F6` · 用户气泡 `--user`: `#172B4D`

## 3. 字体与排版层级（Typography）

- **无衬线字体栈**：`ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`
- **等宽字体栈（用于路径、命令、主机地址、耗时数字）**：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`

| 层级名称 | 字号 | 字重 | 行高 | 字距 | 适用元素 |
| --- | --- | --- | --- | --- | --- |
| **Display Title** | `25px` | `700` | `1.2` | `-0.02em` | 电脑选择页大标题（“选择工作台电脑”） |
| **Brand / Modal Title** | `23–24px` | `700` | `1.25` | `-0.02em` | 访问码门禁 `Codex-Turnloom`（单行不换行）、引导页主标题 |
| **Workspace Header** | `16–16.5px` | `700` | `1.25` | `0` | 对话工作台标题、电脑卡片名称、抽屉顶部电脑名 |
| **Message Body** | `14.5–15px` | `400` | `1.5` | `0` | 用户与 Codex 消息正文（兼顾阅读舒适度与单屏信息密度） |
| **Compact UI / Input** | `13.5–14px` | `500` | `1.45` | `0` | 输入框文本、工具步骤描述、目标条文字、列表项 |
| **Meta / Pill / Chip** | `11–12px` | `600` | `1.2` | `0` | 状态胶囊、模型胶囊、角色眉标、队列项按钮 |
| **Eyebrow / Tag** | `10.5–11px` | `700` | `1.1` | `0.06em` | `PRIVATE MOBILE WORKSPACE`、沙盒框标签 `WRITE ACCESS` |

## 4. 圆角、间距与阴影收敛规范

### 4.1 严格统一的四档圆角（4-Tier Radii）

废除 V1 中混乱的 `6px / 7px / 8px / 12px / 14px / 18px`，全应用严格收敛为 4 档：

1. `--radius-sm: 8px`：目标条、沙盒代码框、队列内嵌子项、小标签。
2. `--radius-md: 12px`：顶栏导航按钮（40×40dp）、审批操作按钮（44dp 高）、工具步骤卡、对话列表项。
3. `--radius-lg: 16px`：消息气泡（用户气泡右下角 `6px`、助手气泡左下角 `6px` 以体现对话指向）、电脑设备卡片、一体式输入工作舱（`.composer-pod`）、权限审批大卡。
4. `--radius-pill: 999px`：主/次大按钮、状态胶囊、模型与插件胶囊、圆形发送/停止/附件按钮。

### 4.2 阴影与材质

- **普通消息气泡 / 设备卡**：`0 2px 8px rgba(15, 23, 42, 0.04)` + `1px solid #E2E5EC`
- **输入工作舱（Composer Pod）**：`0 4px 14px rgba(15, 23, 42, 0.05)`，聚焦时边框变 `#0066CC` 并带 `0 0 0 3px rgba(0, 102, 204, 0.12)` 光晕
- **模态弹窗 / 访问码卡**：`0 20px 48px rgba(15, 23, 42, 0.14)`
- **顶栏与底部输入区背景**：`rgba(255, 255, 255, 0.94)` + `backdrop-filter: saturate(180%) blur(16px)`

检测 Codex Desktop

控制台需要读取本机的 Codex 会话数据，才能把任务同步到手机。请选择检测到的数据目录。

没有自动找到 Codex 数据目录 通常位于 %USERPROFILE%\.codex，或者你设置的 CODEX_HOME。也可以手动选择包含 state_5.sqlite 的目录。

扫码连接手机

打开手机上的 Codex-Turnloom APP，点击「扫码」，扫描下方二维码。扫码后会自动填入地址和访问码。

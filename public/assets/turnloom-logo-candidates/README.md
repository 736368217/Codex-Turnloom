# codex-Turnloom logo candidates

这些 PNG 是四种视觉方向的候选板，每个方向包含 3 张生成结果；每张结果图内又排布了多个小标记变体，方便快速比较构图、配色和识别度。

- `shuttle-thread/`：回梭织线，用织梭和连续线呼应 Turnloom。
- `device-bridge/`：跨设备桥，直接表现手机与电脑的连接。
- `orbit-thread/`：会话轨道，用开放环表达对话持续和返回。
- `pulse-nodes/`：脉冲节点，用节点与流动脉冲表达消息、工具和任务状态。

总览图：`selection-sheet.jpg`。当前只把候选作为设计探索保存，尚未强制替换 Android 正式图标；选定方案后再制作适配各尺寸和安全区的生产资源。

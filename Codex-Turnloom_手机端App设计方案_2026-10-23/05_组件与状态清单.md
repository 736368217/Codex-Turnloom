## 2. 导航组件

### 2.1 原生 AppBar（电脑选择）

- 高度：64dp
- 背景：白色
- 左侧标题：19sp / 700 / `#1D1D1F`
- 右侧动作：`?`（使用指引）、`更新`（检查更新）、`＋`（手动添加）
- 动作热区：44×44dp
- 无阴影；底部不画线（页面背景自然分隔）
- 状态：默认、按下（背景 `#F2F2F7`）

### 2.2 原生连接顶栏

- 高度：52dp
- 背景：白色
- 返回：44×44dp，`‹` 30sp
- 在线点：10sp，宽 22dp；绿 / 红
- 电脑名：16sp / 700，单行省略
- 备注：11sp / `#6E6E73`，单行省略
- 刷新：44×44dp，`↻` 24sp
- 进度条：2dp，操作蓝，仅加载时显示
- 状态：加载中、在线、离线、加载失败

### 2.3 对话顶栏

- 高度：58dp（手机）
- 背景：`rgba(255,255,255,0.9)` + `saturate(180%) blur(20px)`
- 底部：1px `rgba(0,0,0,0.08)`
- 左 padding：58dp（给抽屉按钮）
- 标题：17sp / 600，单行省略
- 副标题：12sp / `#6E6E73`，如“18 条内容 · 思考中”
- 右侧：工具开关（40dp）、刷新（40dp）
- 状态：默认、同步中、同步失败

### 2.4 抽屉标签

- 尺寸：44×44dp
- 位置：左上 8dp / 8dp
- 背景：白色
- 圆角：14dp
- 阴影：`0 8px 24px rgba(0,0,0,0.12)`
- 图标：三条横线，20sp
- 状态：默认、按下、隐藏（抽屉打开时淡出）

### 2.5 对话列表抽屉

- 宽度：`min(88vw, 380dp)`
- 背景：`rgba(250,250,252,0.98)`
- 右侧阴影：`16px 0 34px rgba(38,35,31,0.18)`
- 顶部品牌行：高 76dp
- 搜索 / 新对话：高 42dp
- 对话项：高 ≥56dp
- 分组标题：12sp / 600 / `#6E6E73`
- 选中：`#E7F1FF`
- 状态：打开、关闭、拖动（可选）

### 4.1 角色标签

- 图标 22dp（手机）/ 24dp（桌面）

## 7. 反馈组件

### 7.1 空状态

- 居中，最大宽 360–420dp
- 文案 15–16sp / `#6E6E73`
- 可带一个主按钮
- 场景：未选择对话、空对话、无搜索结果、无电脑、无用量

### 7.2 加载

- 页面级：16dp spinner + 12sp 文案
- 按钮级：按钮内 16dp spinner，保持宽度
- 列表级：骨架行或顶部 2dp 进度条
- 不使用全屏遮罩阻塞操作

### 7.3 Toast / Snackbar

- 短反馈：底部 Toast 2s
- 可恢复错误：Snackbar + 操作按钮（重试 / 撤销）
- 不使用模态对话框展示普通成功提示

## 9. 内容规范

- 按钮使用动词：`发送`、`停止`、`保存`、`重发`、`扫描二维码`
- 状态使用名词 / 形容词：`运行中`、`等待处理`、`已结束`、`离线`
- 错误使用“原因 + 下一步”：`发送失败：网络超时，请重试`
- 不使用“确定 / 取消”作为唯一说明；标题要说明对象
- 中文标点使用全角；数字与英文前后留空格
- 单位：`秒`、`分钟`、`条`、`个对话`
- 时间：`10/23 16:19`；跨年显示 `2025/10/23`

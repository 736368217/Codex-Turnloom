# 04 页面规格与交互说明

> 基准画布：390×844dp（Android 手机，竖屏）。所有尺寸为设计建议值，落地时可取整到 2dp。
> 视觉参考：`screens/` 目录下的 7 张页面示意图 + 1 张全部页面总览。

## 4.0 全局规则

### 4.0.1 安全区

- 顶部状态栏：`env(safe-area-inset-top)`；Android 原生壳状态栏白色、深色图标
- 底部手势区：`env(safe-area-inset-bottom)`；输入区底部至少 12dp
- 左右：`env(safe-area-inset-left/right)`

### 4.0.2 导航

- 原生页面：系统返回键返回上一级
- WebView：返回键先交给网页处理（关闭浮层 / 抽屉），再退出到电脑列表
- 抽屉：左边缘滑入或点左上按钮；遮罩点击关闭
- 对话框：返回键 / 遮罩 / 关闭按钮均可关闭

### 4.0.3 加载与错误

- 页面级加载：轻量 spinner + “加载中”，不使用全屏白屏
- 列表加载：保留旧内容，顶部细进度条
- 错误：在内容区显示“原因 + 下一步”，不使用只带“确定”的弹窗
- 网络中断：顶栏副标题显示“同步暂时失败 · 原因”，不清空消息

## 4.3 S03 / S04 添加电脑

### S03 扫码

- 全屏相机，黑色背景
- 顶部返回按钮（44dp，白色）
- 中间取景框：约 240×240dp，四角白色描边，圆角 12dp
- 下方提示：`将电脑端显示的设备码放入框内` 14sp 白色
- 底部说明：`设备码包含电脑地址和访问码，请勿分享` 12sp，白色 70%
- 识别成功：短暂成功态 → 自动返回
- 识别失败：Toast + 继续扫描
- 相机权限拒绝：说明卡 + “打开设置”

### S04 手动添加

对话框 / 全屏页面（建议 390dp 下用底部抽屉，桌面端用对话框）：

| 字段 | 规格 |
| --- | --- |
| 标题 | `添加电脑` / `编辑电脑` 18sp/600 |
| 电脑名称 | 必填，示例“办公室电脑” |
| 地址 | 必填，`http(s)://host:port`，键盘 URL |
| 访问码 | 必填，密码输入，可显示/隐藏 |
| 备注 | 可选，手机本地备注 |
| 操作 | 取消 / 保存；保存中禁用 |

校验：

- 地址必须以 `http://` 或 `https://` 开头
- 访问码不能为空
- 保存失败：字段下方红字，不关闭对话框

## 4.5 S06 访问码门

### 布局

- 全屏浅灰背景 `rgba(245,245,247,0.94)` + 20px 模糊
- 卡片：最大宽 390dp，内边距 28dp，圆角 8dp（建议 redesign 用 16dp），阴影 `0 24px 70px rgba(0,0,0,.12)`
- Logo：48×48dp，圆角 11dp
- Eyebrow：`PRIVATE MOBILE WORKSPACE` 11sp/700，字距 0.08em，操作蓝
- 标题：`Codex-Turnloom` 28sp/600（小屏建议 24–26sp 防止换行）
- 说明：`连接这台电脑，继续查看和控制正在运行的 Codex。` 15sp，`#6E6E73`，行高 1.5

## 4.6 S07 对话列表抽屉

### 布局

- 宽度：`min(88vw, 380dp)`；390dp 屏幕约 343dp
- 背景：`rgba(250,250,252,0.98)`，右侧 16px 阴影
- 顶部：品牌行，高 76dp；Logo 32×32dp；标题 19sp/700；副标题“12 个对话” 12sp；右侧关闭 `‹` 40dp
- 搜索行：左右 14dp，下 12dp；搜索框高 42dp，全圆角，`#ECECF0` 底；新对话按钮高 42dp，全圆角，蓝底白字
- 排序行：左右 14dp；`排序` 12sp；右侧下拉 `按项目 / 按最近`
- 列表：可滚动；对话项高 ≥56dp，圆角 8dp，间距 4dp
- 分组标题：12sp/600，`#6E6E73`，上下 4/7dp，右侧折叠箭头
- 对话项：标题 15sp/500，单行省略；状态 11sp + 6dp 圆点；提醒标记 11sp 操作蓝
- 选中态：`#E7F1FF` 背景，无边框
- 底部：高 48dp + 安全区；左侧“使用指引” 13sp/600 操作蓝；右侧“连接保持在你的设备之间” 10sp `#6E6E73`

### 状态

- 加载中：保留列表，顶部细进度条 / 或 3 个骨架行
- 空：`还没有对话` + 说明

- 分组折叠：箭头旋转 -90°，内容隐藏
- 选中：浅蓝底
- 长按：上下文菜单（置顶 / 取消置顶、开启/关闭完成提醒、复制深度链接）
- 提醒已开：状态行右侧蓝字“提醒已开”

### 交互

- 搜索：输入即过滤，不区分大小写；清空恢复
- 新建：插入草稿项并关闭抽屉
- 长按：520ms 触发，震动 12ms
- 点击遮罩 / 返回 / 关闭按钮：关闭抽屉
- 切换排序：本地保存选择
- 分组折叠：本地保存状态

### 交互

- 点击抽屉按钮：打开列表
- 工具开关：默认关闭；开启后显示工具消息
- 刷新：保留阅读位置，更新消息
- 滚动到顶部：加载更早一页，保持当前阅读位置
- 滚动到底按钮：仅当不在底部时出现
- 点击图片：全屏预览
- 点击文件：下载 / 打开
- 点击网页链接：系统浏览器
- 长按消息：创建分支（可选）
- 输入 `@`：插件选择；输入 `/`：技能选择
- 发送：立即出现乐观气泡；发送中 / 失败 / 重试
- 运行中：发送方式必须选择“排队”或“插入”；显示停止按钮

### 状态

- 加载中：spinner + “加载中”
- 空对话：`这个对话暂时没有可展示内容。`
- 新对话草稿：`输入消息开始新对话。`
- 正常：消息流 + 输入区
- 思考中：顶栏状态 + 思考气泡 + 停止按钮
- 等待处理：顶栏“需要处理” + 交互气泡
- 发送中：用户气泡下方“正在发送中”
- 发送失败：`发送失败` + `重发`；保留原文和图片
- 同步失败：顶栏副标题“同步暂时失败 · 原因”，不清空内容
- 只读：输入区禁用，提示“只读模式”

## 4.8 S09 权限审批

### 布局

- 作为消息流中的 `interaction` 气泡，背景 `#FFF0F0`，1px 浅红边框，圆角 12dp
- 顶部 meta：`需要处理` 11sp 红
- 标题：`等待确认` 13sp/750，深红 `#7D2C28`
- 请求正文：15–16sp，说明要做什么、影响范围
- 补充说明：12sp，`#6E6E73`
- 按钮组：横向 wrap，间距 8dp，上 12dp
  - 主按钮“是”：浅绿底 `#EAF4EF`，深绿字 `#1F5F50`，高 32dp（建议 44dp）
  - 次按钮“否”：白底，暖棕字 `#6D4C18`
  - 次按钮“一直是”：同主按钮
- 提交结果：
  - 提交中：`正在提交审批...` + 禁用按钮
  - 成功：`审批已提交`，浅绿底
  - 失败：`审批提交失败：原因`，红色，保留重试
- 桌面端已处理：显示“桌面端已处理”，按钮禁用

### 交互

- 点击“是 / 否 / 一直是” → 立即禁用全部按钮 → 提交
- 提交成功：气泡内显示结果，不弹 Toast
- 提交失败：恢复按钮 + 错误文字
- 同一请求只允许提交一次

## 4.9 S10 运行中排队 / 插入

### 布局

- 仅当任务运行中（thinking）显示
- 输入区上方队列条：
  - 背景 `#F1F7F5`（建议改中性浅灰 / 浅蓝）
  - 1px `#C9D8D3` 边框，圆角 7dp（建议 12dp）
  - 标题行：`已排队 2 条 · 最后一条：…` 12sp，右侧 `×` 24dp
  - 队列项：上边框 1px，标签 11sp，预览 12sp 单行省略；右侧操作按钮“转为插入 / 编辑 / 取消”，高 28–32dp
- 输入框 placeholder：`当前任务完成后发送`（排队）/ `立即插入当前任务`（插入）
- 分段控件：`排队` / `插入`，高 30dp，圆角 7dp；选中浅绿底（建议操作蓝浅底）
- 停止按钮：40dp 圆形，红描边，红方块图标
- 发送按钮：蓝色圆形，箭头向上

### 状态

- 队列为空：不显示队列条
- 排队中：显示队列条 + 发送方式“排队”选中
- 插入中：发送方式“插入”选中，发送后提示“已插入当前任务”
- 转为插入失败：恢复队列项 + 错误提示
- 任务刚好完成：提示“原任务刚好完成，这条消息已作为下一步发送。”

### 交互

- 发送前可选择排队 / 插入；选择持久化到本地
- 队列项“编辑”：把原文和图片放回输入框，移除队列项
- 队列项“取消”：移除并刷新队列
- “转为插入”：调用 steer，成功则移除；失败恢复
- 全部取消：二次确认
- 停止：二次确认（可选），成功后任务进入已结束

## 4.10 S11 目标详情 / 编辑

### 目标条

## 4.16 手势与反馈

- 点击：按下态缩放 0.97–0.99，或背景变深 4–6%
- 长按对话：520ms，震动 12ms，弹出上下文菜单
- 滚动：惯性滚动；到顶加载更早消息；到底显示“回到底部”按钮
- 下拉：暂不作为主要交互
- 键盘：输入区随键盘上移；`adjustResize`；发送后保持键盘
- 图片预览：双指缩放，单击隐藏/显示控件，返回关闭
- Toast：短操作反馈 2s；错误可用 Snackbar + 重试

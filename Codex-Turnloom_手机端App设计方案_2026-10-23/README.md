# Codex-Turnloom 手机端 App 设计方案

> 版本：2026-10-23
> 用途：交给设计 AI / 外部设计师做手机端重设计
> 基准画布：Android 390×844dp

## 这是什么

这是一份**设计交接包**，不是安装包，也不是代码仓库。

它把 Codex-Turnloom 目前手机端的产品结构、页面清单、视觉规范、组件状态和关键交互整理成一套可直接阅读的设计资料，并附上当前实现示意图与品牌素材。

Codex-Turnloom 是一个私有、自托管的移动工作台：电脑上运行 Codex Desktop，手机通过局域网或 HTTPS 连接电脑上的本机服务，查看对话和任务状态、处理权限审批、发送消息、排队/插入、停止任务，并在多台电脑之间切换。

## 建议使用方式

### 方式 A：直接给设计 AI

1. 上传整个压缩包（或至少上传 `00`–`06`、`design-tokens.json`、`screens/`）；如果只能传一个文件，用 `Codex-Turnloom_手机端App设计方案_完整版.md`
2. 打开 `06_给AI的设计任务书.md`
3. 把「6.12 简短版提示词」或整份任务书粘贴给 AI
4. 要求对方先复述理解，再开始设计
5. 用 `07_设计评审与验收清单.md` 验收

### 方式 B：给人类设计师

1. 先读 `00_一页纸速览.md`
2. 再读 `01`、`02`，理解产品和信息架构
3. 用 `03`、`04`、`05` 作为视觉和组件依据
4. 看 `screens/` 了解当前实现的长相和内容密度
5. 用 `06` 对齐交付范围
6. 用 `07` 做评审

## 关于截图

`screens/` 中的 8 张图是**基于当前实现（CSS / 页面结构 / Android 原生布局）还原的 390×844 示意图**，用于说明信息结构、内容密度和当前视觉状态。

它们不是营销稿，也不是最终设计稿；图中使用虚构的测试数据，不含真实对话、访问码、私人地址或个人信息。

旧版实机截图未放入本包，避免与当前视觉混淆；如需历史参考，可查看项目仓库 README。

## 重要说明

- 当前实现是一个**过渡状态**：主界面已经采用中性灰 + 单一操作蓝，但部分旧组件仍有绿色/暖黄残留（目标条、队列、审批等）
- `03_视觉设计系统.md` 第 14 节列出了当前实现的已知不一致点，重设计时应作为输入，而不是照搬
- 触控目标、圆角、状态色、工具开关的视觉权重，都是本次重设计需要修正的重点
- 设计时请保留现有信息架构和功能范围；不要把它做成远程桌面、完整 IDE 或社交聊天 App

## 隐私

本包不包含：

- 真实对话内容
- 访问码、Token、密钥
- 真实的公网地址、内网 IP、主机名
- 用户个人信息

截图与示例中的电脑名、地址、对话均为虚构占位内容。

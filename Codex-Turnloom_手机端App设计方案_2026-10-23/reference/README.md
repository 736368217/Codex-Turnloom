# 实现参考文件

本目录用于给需要对照现有实现的设计师 / 开发查看，不是设计的唯一依据。

## 文件

- `current-styles.css`：当前 Web 工作区的完整样式（约 3,600 行）
- `current-index.html`：当前 Web 工作区的页面结构

## 使用建议

1. **优先看 `design-tokens.json` 和 `03_视觉设计系统.md`**
   - 当前 CSS 包含多轮历史叠加和旧组件规则，不能直接当作最终设计系统
   - 例如：主界面已切换为操作蓝，但队列、目标、审批等仍有绿色 / 暖黄残留
2. 需要确认某个组件的真实尺寸、圆角、字号时，再查 CSS
3. 不要直接复制 CSS 里的旧色值；以设计令牌为准
4. 当前实现中部分触控目标为 32–40dp，低于 44dp 建议，重设计时应修正
